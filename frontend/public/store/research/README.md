# Подборка для информационной витрины

Дата исследования: 8 октября 2026 года. Подборка составлена по разнообразию
форм и наличию открытых фотографий. Она не подтверждает ассортимент компании,
наличие моделей или место производства конкретного экземпляра. Цены не исследовались.

Дополнительные фотографии с фоном собраны в [описании галерей](./gallery/README.md).
Для каждой модели выбраны прозрачное превью и два дополнительных снимка;
различия исполнений и общие исходные кадры указаны отдельно.

Десять исходных PNG сохранены без изменений. У каждого проверено наличие
прозрачных пикселей в alpha-канале. `selection-preview.jpg` — обзорный коллаж
на тёмном фоне, а не макет страницы. `sources.json` содержит исходные метаданные
Commons, включая авторство и лицензии; HTML в нём является внешними данными
и не предназначен для непосредственного вывода на сайте.

## Замечания по качеству

- G36, MP7, USP и PPK-L визуально читаются на тёмном фоне. G36 шириной 1150 px
  лучше не растягивать на всю ширину большого экрана.
- HK416N мягче остальных снимков; пригоден для небольшого превью, но не как
  крупная центральная фотография.
- G3 показывает два ракурса сразу. Для карточки с одним силуэтом нужен другой
  исходник либо отдельно обозначенная обрезка.
- У P99 метаданные авторства содержат посторонний текст. Он не включён в
  подпись; имя автора указано с оговоркой, присутствующей на странице Commons.
- `g3-scene.jpg` — резервный музейный снимок, автор Mohit S, [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/),
  [источник](https://commons.wikimedia.org/wiki/File:Heckler_%26_Koch_G3._(49193229971).jpg).
  Из-за бликов и водяного знака не выбран для hero.
- `g36-exhibition.jpg` — выставочный снимок G36 AC4 на столе, 1024 × 768 px.
  Автор Boevaya mashina, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/),
  [источник](https://commons.wikimedia.org/wiki/File:HK_G36_AC4_Hensoldt_ZO_4x30i_2023.jpg).
  Это другое исполнение G36, чем в прозрачном превью; подпись должна сохранять
  обозначение AC4. Размер подходит для галереи, но ограничивает крупный hero.
